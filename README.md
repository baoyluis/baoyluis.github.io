# Luis Baoy | Personal Portfolio

Personal portfolio website, built from my LinkedIn profile.

**Live site:** https://baoyluis.github.io

## About

A fast, lightweight, single-page site showing my professional background: experience, education, skills, and contact details.

## Built with

- HTML and CSS (no frameworks, no build step)
- Hosted free on [GitHub Pages](https://pages.github.com/)

## Project structure

```
.
├── index.html     # The whole site (HTML, CSS and a tiny script in one file)
└── README.md
```

## Run locally

1. Clone the repository:
   ```
   git clone https://github.com/baoyluis/baoyluis.github.io.git
   ```
2. Open `index.html` in your browser.

## Updating the site

Edit the files, commit the changes, and push. GitHub Pages republishes automatically within a few minutes.
